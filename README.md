# 🤖 VOICE AGENT 20 — AI 보이스 에이전트 + 💻 코드 스튜디오 (설치형 앱)

남자 10명 · 여자 10명, **스무 명의 AI 초상화와 목소리**로 대화하고,
말로 명령하면 **계획 → 도구 선택 → 실행** 3단계로 일을 끝내는 보이스 에이전트입니다.
“하이 보이스”라고 부르면 비프음과 함께 “네, 듣고 있어요!”라고 답하고 명령을 기다립니다(빅스비 방식).
**“계산기 웹앱 코드 짜 줘”**처럼 말하면 **음성 코딩 도우미(💻 코드 스튜디오)** 가 완성된 코드를 만들어
그 자리에서 실행해 볼 수 있습니다.
API 키가 없어도 내장 데모 두뇌·내장 도구·내장 코드 생성기로 바로 동작합니다.

## 🧠 LLM + 🤖 에이전트 — 두 개의 두뇌

상단의 **🧠 LLM / 🤖 에이전트 / ✨ 자동** 토글로 엔진을 고릅니다. 기본은 **자동**입니다.

- **자동**: 명령이면 에이전트가, 대화면 LLM이 답합니다.
- **LLM 대화**: 모든 말을 캐릭터의 목소리로 대화합니다.
- **에이전트**: 명령을 3단계 타임라인으로 처리하고 결과를 음성으로 보고합니다.

에이전트는 명령을 받으면 아래 세 단계를 화면에 그대로 보여 줍니다.

1. **계획 수립** — 목표를 2~3단계 실행 계획으로 쪼갭니다.
2. **도구 선택 · MCP 연결 확인** — 필요한 도구를 고르고 연결 상태를 확인합니다.
   연결이 안 된 도구는 **[바로 연결]** 버튼이 뜨고, 누르면 연결한 뒤 같은 명령을 즉시 다시 실행합니다.
3. **도구 실행 · 결과 보고** — 실제로 실행하고 결과를 텔레프롬프터에 쓰고 음성으로 읽습니다.

| 도구 | 되는 일 | 예시 명령 |

| 📅 일정 장부 | 날짜·시간을 해석해 일정 저장 | “내일 오후 3시 회의 일정 잡아줘” |

| 💻 코드 스튜디오 | 음성으로 웹앱·게임·파이썬 코드 생성 + 즉시 실행 | “계산기 웹앱 코드 짜 줘” |

메모·할 일·일정은 **이 브라우저(localStorage)에만** 저장되고 서버로 보내지 않습니다.

## 💻 음성 코딩 도우미 — 코드 스튜디오

말이나 글로 코딩을 부탁하면 에이전트가 **💻 코드 스튜디오**를 열고 완성된 코드를 채워 줍니다.
API 키가 없어도 아래 요청은 **실제로 완벽히 동작하는 코드**가 만들어집니다.

| 말해 보세요 | 만들어지는 것 |
| --- | --- |
| “계산기 웹앱 코드 짜 줘” | 사칙연산·퍼센트 계산기 (키보드 지원) |
| “디지털 시계 만들어 줘” | 초 단위 디지털 시계 (12/24시간 전환) |
| “타이머 만들어 줘” | 카운트다운 타이머 (1·3·5·10분, 종료 비프음) |
| “랜덤 뽑기 게임 만들어 줘” | 돌림판 룰렛 (항목 편집 가능) |
| “주사위 게임 만들어 줘” | 주사위 두 개 굴리기 |
| “메모장 HTML 짜 줘” | 자동 저장 메모장 (.txt 내려받기) |
| “투두 리스트 앱 만들어 줘” | 할 일 목록 (브라우저 저장) |
| “클릭커 게임 만들어 줘” | 미니 클릭커 게임 (업그레이드·자동 수집) |
| “숫자 맞추기 게임 만들어 줘” | 1~100 숫자 맞추기 |
| “파이썬 구구단 코드 짜 줘” | 구구단 2~9단 출력 프로그램 |
| “파이썬 계산기 만들어 줘” | 터미널 사칙연산 계산기 |
| “배경색 파란색으로 바꿔 줘” | 직전 코드의 배경색만 바꿔서 다시 그림 |
| “제목을 내 시계로 바꿔 줘” | 직전 코드의 제목 교체 |

코드 스튜디오는 세 개의 탭으로 이루어집니다.

1. **코드** — 생성된 코드를 직접 보고 고칠 수 있는 다크 코드 에디터입니다. 위쪽에 언어와 줄 수가 표시됩니다.
2. **▶ 실행 미리보기** — HTML/CSS/JS 코드는 `sandbox="allow-scripts"` iframe 안에서 즉시 실행됩니다.
   폰에서도 방금 만든 계산기·룰렛·게임을 그 자리에서 눌러 볼 수 있습니다.
   (파이썬 코드는 브라우저에서 실행되지 않으므로 파일로 저장해 PC에서 실행합니다.)
3. **🐙 GitHub에 저장** — 저장소·파일 경로·커밋 메시지를 넣고 저장합니다.
   ⚙️ MCP 허브에 GitHub 토큰이 있으면 Contents API로 **실제 커밋**까지 하고,
   토큰이 없으면 **💾 파일 저장** 후 GitHub 업로드 안내를 보여 줍니다.

아래 버튼도 함께 씁니다.

- **📋 코드 복사** — 코드 전체를 클립보드로 복사
- **💾 파일 저장** — `.html` 또는 `.py` 파일로 내려받기
- **▶ 실행** — 미리보기 탭을 열고 다시 실행

실제 LLM 키(OpenAI·Claude·Gemini·Ollama)를 넣으면 시스템 프롬프트가 코드 블록 반환 규칙으로 바뀌고,
응답에 담긴 코드를 자동으로 뽑아 코드 스튜디오에 넣습니다. 코드 블록 밖의 설명만 음성으로 읽습니다.

## 🎙️ 빅스비식 호출어

- 마이크 옆 **🎙️ 호출어 대기** 버튼을 켜면 “하이 보이스”를 계속 듣습니다.
- 호출어만 말하면 **비프음 + “네, 듣고 있어요!”** 후 명령을 기다립니다.
- “하이 보이스, 깃허브 확인해줘”처럼 **한 번에** 말하면 곧바로 실행합니다.
- “헤이 보이스”, “하이 에이전트”, “헤이 민준”도 알아듣고, ⚙️ 설정에서 **원하는 호출어를 직접 입력**할 수 있습니다.
- 이름(민준아·서연아)만 불러도 호출로 인식합니다.
- 화면의 **🎙️ 빅스비처럼 말해 보세요** 칩을 누르면 그 명령이 바로 실행됩니다.

## 📲 안드로이드 폰에 앱으로 설치하기

브라우저는 **https 주소**로 열린 페이지에서만 앱 설치를 허용합니다.
(`file://` 로 파일을 열면 설치는 안 되고 화면 표시만 됩니다. 앱 안의 `📲 앱 설치` 버튼을 누르면 이 안내가 다시 뜹니다.)

### 1분 설치 — GitHub Pages에 올리기 (가장 쉬운 방법)

1. github.com 에 로그인하고 **New repository** 로 새 저장소를 만듭니다. (예: `voice-agent-20`, Public)
2. 이 폴더(`voice-agent-app`) 안의 파일을 **전부** 저장소에 올립니다.
   - 웹 화면: `Add file` → `Upload files` → 폴더째 끌어다 놓기
   - 또는 PC 터미널에서:
     ```bash
     cd voice-agent-app
     git init && git add . && git commit -m "voice agent 20"
     git branch -M main
     git remote add origin https://github.com/<내아이디>/voice-agent-20.git
     git push -u origin main
     ```
3. 저장소 → **Settings → Pages** → Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 저장합니다.
4. 1~2분 뒤 `https://<내아이디>.github.io/voice-agent-20/` 주소가 열립니다.
5. 폰 **크롬**에서 그 주소를 엽니다.
6. 오른쪽 위 **⋮** → **앱 설치** (또는 **홈 화면에 추가**) → **설치**.
   - 앱 상단의 **📲 앱 설치** 버튼이 보이면 그걸 누르는 게 가장 빠릅니다.
7. 홈 화면의 **VOICE AGENT 20** 아이콘을 누르면 주소창 없는 전체 화면 앱으로 열립니다.

### 삼성 인터넷

아래 **≡** 메뉴 → **페이지 추가** → **홈 화면에 추가** → **추가**.

### PC에서 잠깐 시험할 때

```bash
cd voice-agent-app
python3 -m http.server 8000
```
PC 브라우저에서 `http://localhost:8000` 을 엽니다. (localhost 는 예외적으로 설치가 허용됩니다.)

## 설치하면 좋은 점

- **주소창 없는 전체 화면** — 진짜 앱처럼 실행됩니다.
- **오프라인 실행** — 앱 화면과 스무 명의 초상화가 기기에 저장되어, 비행기 모드에서도 열립니다.
  (실제 LLM 답변·GitHub·날씨는 인터넷이 필요하고, 끊기면 내장 데모가 대신 답합니다.)
- **홈 화면 바로가기** — 길게 누르면 민준·서연·하준·별하 채널로 바로 들어갈 수 있습니다.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| `📲 앱 설치` 를 눌러도 설치 창이 안 뜸 | https 주소인지 확인하세요. `file://` 이면 설치 불가입니다. 크롬 ⋮ 메뉴의 "앱 설치"를 직접 눌러도 됩니다. |
| 호출어를 불러도 반응이 없음 | Chrome 권장. 주소창 왼쪽 자물쇠 → 마이크 허용. 호출어 대기 버튼이 켜져 있는지 확인하세요. |
| 호출어가 자꾸 다르게 인식됨 | ⚙️ 설정 → 호출어를 짧게(예: “하이 보이스”) 바꾸고 [테스트]로 확인하세요. |
| GitHub 도구가 미연결로 뜸 | 에이전트 카드의 **[바로 연결]** 을 누르면 연결 후 같은 명령을 다시 실행합니다. |
| 날씨·GitHub 조회 실패 | 네트워크 또는 브라우저 보안 정책(`file://`) 때문입니다. https 주소로 열면 됩니다. |
| 목소리가 안 들림 | 기기 TTS(삼성/구글 음성) 설치 여부를 확인하세요. 글은 항상 정상 표시됩니다. |
| 화면이 예전 것임 | 브라우저 새로고침 두 번, 또는 앱을 지우고 다시 설치하세요. |
| 코드 미리보기가 비어 있음 | **▶ 실행**을 다시 누르세요. 코드를 고친 뒤에는 실행 탭에서 0.6초 뒤 자동으로 다시 그립니다. |
| 🐙 GitHub 저장이 실패함 | ⚙️ MCP 허브에 토큰을 넣고, 그 토큰에 `Contents: write` 권한과 저장소 접근이 있는지 확인하세요. 토큰이 없으면 파일 저장으로 내려받아 직접 올리면 됩니다. |
| 파이썬 코드가 실행되지 않음 | 브라우저는 파이썬을 실행하지 않습니다. **💾 파일 저장**으로 `.py` 를 받아 PC에서 `python3 파일.py` 로 실행하세요. |
